# Bom pagador ou inadimplente? — Regressão logística, sem fórmulas

Explicador visual e interativo de regressão logística, gerado pelo Sonnet 5.5
(bench-html, item HTML-015) e adaptado para o tema de risco de crédito.

- Abra `https://marcoseilert.github.io/bench-html-logreg/` no celular ou no desktop.
- Arquivo único, 100% autocontido: sem bibliotecas, sem CDN, sem imagens externas.
- Dados simulados para fins didáticos.
